## 📘 Deskripsi
Tugas ini merupakan proyek awal pada mata pelajaran **Pemrograman / Praktik**, dengan fokus pada **pengenalan dasar HTML**.  
Tujuan utamanya adalah agar siswa memahami bagaimana cara membuat struktur halaman web sederhana menggunakan elemen-elemen dasar HTML.

---

## 🎯 Tujuan Pembelajaran
1. Memahami fungsi dan struktur dasar dokumen HTML.  
2. Mengenal elemen-elemen utama seperti `<head>`, `<body>`, `<header>`, `<section>`, dan `<footer>`.  
3. Mampu menyusun halaman web sederhana yang terstruktur dengan baik.  
4. Menumbuhkan kebiasaan dokumentasi proyek sejak awal pembelajaran.

---

## 📂 Isi Tugas
File utama yang dikumpulkan:
- **`pertemuan_0.html`** → berisi latihan membuat halaman web dasar.
- **`README.md`** → dokumentasi singkat untuk menjelaskan isi dan tujuan tugas.

---

## 🧠 Penjelasan Tugas
Pada tugas pertemuan pertama ini, siswa diminta untuk membuat satu file HTML sederhana yang berisi:
- Struktur dasar halaman web.
- Identitas siswa (nama dan kelas) di dalam konten.
- Penjelasan singkat tentang apa yang dipelajari atau dibuat.

Tugas ini menjadi pondasi untuk pembelajaran selanjutnya, seperti penambahan **CSS**, **JavaScript**, dan pengenalan **struktur proyek web** yang lebih kompleks.

---

## 🚀 Cara Melihat Tugas
1. Buka folder proyek `pertemuan_0`.
2. Klik dua kali pada file `pertemuan_0.html`.
3. Halaman akan terbuka otomatis di browser dan menampilkan hasil tugas.
