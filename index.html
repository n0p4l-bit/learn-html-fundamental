1. Tujuan

  • Peserta didik dapat memahami dasar pemrograman server-side menggunakan HTML.
  • Peserta didik mengetahui sintaks-sintaks dasar HTML.
  • Peserta didik dapat membuat tata letak (layout) sederhana menggunakan HTML.

2. Dasar Teori

HTML (HyperText Markup Language) merupakan bahasa markup untuk mendefinisikan suatu teks yang dapat dibaca oleh browser. Browser seperti Google Chrome, Mozilla Firefox, akan menterjemahkan kode HTML menjadi tampilan visual halaman web.

Beberapa Elemen HTML yang Sering Digunakan:

Tag Fungsi
<h1> - <h6> Judul atau heading
<p> Paragraf teks
<a> Hyperlink
<img> Menampilkan gambar
<br> Garis baru
<hr> Garis pemisah (horizontal)
<b> Teks tebal
<i> Teks miring
